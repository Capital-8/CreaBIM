# Keyboard shortcuts

Every key CreaBIM knows. This page is made from the app's own menus and key list, so it always matches the version you are running.

Keys reach the views even after you click in a menu bar or the browser. Most keys act on the view under the pointer.

**Coming from another program?** *Settings › Keymap › I come from* sets the edit keys and the mouse to Revit's (MV, RO, CO, MM, OF, TR), ArchiCAD's (Ctrl+D, Ctrl+E…), AutoCAD's (M, RO, SC, CO, MI, O), SketchUp's (M, Q, S, F) or Blender's. Letters typed one after the other, such as MV, count as one key. Below it, any command's key can be typed over, and a reset puts it back. The first launch asks the same on the splash.

> **Tip:** You don't need to learn these. Every command is also on a menu, a button or the right-click menu, and `Ctrl+K` finds any of them by name.
