# CreaBIM's Chinese fonts

Three fonts cut to GB2312 level 1 (the 3,755 most used hanzi), Latin, punctuation and the drawing marks, by `tools/fonts/ship_han.py`. Each is a Modified Version under the SIL Open Font License 1.1, renamed because the originals reserve their names.
